# ConverterApp

## Beschreibung

ConverterApp ist eine einfache und benutzerfreundliche Anwendung zum Konvertieren verschiedener Werte. Das Ziel des Projekts war es, eine übersichtliche und leicht verständliche Anwendung zu entwickeln, die als Lern und Übungsprojekt dient.

## Funktionen

* Einfache und intuitive Benutzeroberfläche
* Schnelle und zuverlässige Umrechnungen
* Übersichtlicher und gut strukturierter Quellcode
* Leicht erweiterbar für weitere Konvertierungstypen

## Installation

Repository klonen:

```bash
git clone https://github.com/ViniweiReal/Converterapp.git
```

In das Projektverzeichnis wechseln:

```bash
cd Converterapp
```

Das Projekt mit der jeweiligen Entwicklungsumgebung öffnen und starten.

## Einsatz von KI

Für dieses Projekt wurde experimentell künstliche Intelligenz als Unterstützung eingesetzt. Ich wollte die Möglichkeiten meines ChatGPT Pro Abonnements im Entwicklungsprozess testen und herausfinden, wie sich KI sinnvoll zur Verbesserung eines Projekts einsetzen lässt.

Die KI wurde unter anderem genutzt, um:

* Code zu optimieren
* Verbesserungsvorschläge für Struktur und Lesbarkeit zu erhalten
* Fehler schneller zu identifizieren
* Die Dokumentation zu überarbeiten

Alle Vorschläge wurden geprüft und bei Bedarf angepasst. Die KI diente ausschließlich als unterstützendes Werkzeug und ersetzte nicht die eigene Entwicklung oder Entscheidungsfindung.
